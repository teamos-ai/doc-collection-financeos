## Research sequence

1. **Reconcile existing sources first.** Extract relevant Australian broker/lender PDFs and record publisher, product, channel, date/version, source URL and exact page. Verify that each PDF really contains request requirements. Deprioritise inspection, commercial/asset lending and unrelated marketing guides outside the current module.
2. **Build the Australian naming register.** One stable key, preferred client name, common aliases, issuer, what it proves and easy-to-confuse documents. Keep bank credit evidence distinct from employer payslips. No unsupported universal claim about American terminology.
3. **Audit scenario coverage.** For each applicant/entity/account and loan stage, map inputs → requested document → alternatives → count/history → freshness → reason. Separate required versus conditional evidence and distinguish coverage from file count.
4. **Research only unresolved cells.** Recheck current official lender/broker-channel sources for the five nominated lenders; use official ATO material for tax-document terminology. Supplement with Australian broker checklists to test client-facing clarity, not establish universal policy. If current broker policy is gated, record the gap instead of inferring it from an old public PDF.
5. **Reconcile exclusions and conflicts.** New external requirements do not silently restore removed documents. Mark broker-handled exceptions. Preserve fixed founder defaults while documenting lender differences. Do not import the old research specification's FileInvite recommendation as an approved architecture.
6. **Review proposed rules with Tumai.** Present the short list of unresolved decisions after completing independent work. No broker period override; controlled standards maintenance only.
7. **Prepare builder-ready rules.** Deliver a versioned naming register, scenario matrix, evidence/source register, conflict/gap log and worked examples. Then reflect approved rules in the unified board and intake.
